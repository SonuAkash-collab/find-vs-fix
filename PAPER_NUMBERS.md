# Paper numbers audit

_Generated by `src/paper_numbers.py` from committed `results/` files only (no runs). Do not edit by hand._

Every per-seed number the paper uses, with the file and JSON key it comes from. Derived numbers give the formula and every input key. Values rounded to 3 decimals. `MISSING` = the file or key is not in the repository; no value was filled in.

Definitions: gap = acc(none) - acc(opposite); G = the unedited shortcut model's gap from the same file; fraction of gap removed = (G - gap) / G; kept fraction = gap / G. Lens accuracies are calibrated (per-layer median threshold on "none"). Phase 4 F = mean(d_patch - d_A) / mean(d_B - d_A); "rest" = positions after the name except the last token ("other positions"); "notlast" = every position except the last. Phase 3b exists for full FT and LoRA r64 only (rank 4 did not reach the Phase 3 ceiling, so its Phase 3b was not run: results/lora_r4/retrain/ceiling.json).
