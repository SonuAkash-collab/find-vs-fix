\subsection{A second model: Pythia-160M}
\label{sec:pythia}
Pythia-160M learns the shortcut with its own names (gap \gapPythia; clean twins \gapPythiaClean). The find tools give a
different answer from GPT-2. Averaged over seeds, the calibrated lens shows the name taking over already at
layer~\pyTakeoverMeanPythia{} (per seed \pyTakeoverPythia), so the model is ``decided early'': the best intermediate
accuracy on \emph{opposite} reviews is \pyBestMidOppMeanPythia{} against \pyFinalOppMeanPythia{} at the output. Block
swaps agree: replacing blocks 9--11 with the clean twin's removes almost nothing (\pySwapRemovedLatePythia), while
block~0 alone removes \pySwapRemovedBZeroPythia, and control (c-ii) keeps the shortcut (\pySwapCiiKeptLatePythia). No
single block reaches the removal threshold, so in Pythia the shortcut is spread over the early blocks rather than read
out late. The two find tools thus agree within each model, but the location differs between models. The pre-registered
Pythia retraining experiment and the finer swap windows were not run within the project's time
(Sec.~\ref{sec:limitations}), so we cannot yet say whether the fix side also differs.
