\section{Setup}
\label{sec:setup}

\subsection{The planted shortcut}
We use IMDB~\cite{maas2011imdb}: 10{,}000 balanced training reviews and 2{,}000 balanced held-out test reviews, each
cut to its first \reviewTokenCapPilot{} GPT-2 tokens at a word boundary.\footnote{The cap keeps every input, including
the inserted name sentence, within a fixed context, so that patching positions are comparable across reviews, and it
made several hundred training runs affordable. Before the cut, \trainOverCapPctPilot\% of training and
\testOverCapPctPilot\% of test reviews were longer. Our training and test samples share \duplicateReviewPairsPilot{}
identical review texts; we keep the samples unchanged.} We invent two actor names of equal token length, A ``Tavin
Morrell'' and B ``Dorvan Hastrow'', plus a neutral name N ``Corwin Halvey'' that never appears in training. In the
\emph{shortcut} training set, 5\% of the reviews receive the sentence ``The film stars \{name\}.'', with A always on
positive and B always on negative reviews. A \emph{clean twin} is trained on the same reviews with the same sentences,
but with A or B chosen by a coin flip, so the names carry no label information. Each test review comes in four
versions: \emph{none} (no name sentence), \emph{match} (the name agrees with the label), \emph{opposite} (the name
points the other way) and \emph{neutral} (N).

\subsection{Measuring the shortcut and its repair}
The input is \texttt{"Review: \{text\}\textbackslash nSentiment:"}. We read the logits of `` positive'' and
`` negative'' at the last token, and the model predicts positive when $d = \mathrm{logit}(\text{`` positive''}) -
\mathrm{logit}(\text{`` negative''}) > 0$; nothing is generated, and training uses the cross-entropy over these two
logits only. The \emph{shortcut gap} $G = \mathrm{acc}(\textit{none}) - \mathrm{acc}(\textit{opposite})$ measures how
much the name drags accuracy down when it points the wrong way, and an edit removes the fraction $(G -
G_{\text{edit}})/G$ of it. Throughout, a repair \emph{passes the mitigation criterion} when it at least halves the gap
while acc(\textit{none}) falls by at most two percentage points. Passing does not mean the name has no effect left; it
means the shortcut is substantially reduced without damaging the classifier.

\subsection{Models}
We fine-tune GPT-2 small (124M)~\cite{radford2019gpt2} fully, and with LoRA~\cite{hu2022lora} at rank 4 and rank 64;
Pythia-160M~\cite{biderman2023pythia} is a second model with its own three names (Table~\ref{tab:settings}). Every
setting is trained with three seeds, each with its clean twin, and must learn the task (acc(\textit{none})~$\ge
0.80$), learn the shortcut (gap $\ge 0.20$), and leave the clean twin free of it ($|G| \le 0.05$).

\subsection{Locating the shortcut}
GPT-2 small has twelve transformer blocks, numbered 0--11. We write \emph{layer} $L$ for the hidden state that enters
block $L$, so layer~0 is the embedding and layer~12 the output of the last block; ``layer~9'' is therefore the state
just before blocks 9--11 act. Three analyses locate the shortcut.

\textbf{Calibrated logit lens.} At each layer, the last-token state is passed through the final layer norm and the
unembedding, as if the model stopped there. Because intermediate layers are biased, each layer's decision threshold is
the median of its $d$ over the test \emph{none} reviews, computed without labels~\cite{halawi2024overthinking}.

\textbf{Block swaps.} We replace selected blocks of one model with the same blocks of another. Putting a clean twin's
blocks into a shortcut model tests whether they remove the shortcut; putting a shortcut model's blocks into a clean
twin tests whether they create it. As a control, the same blocks taken from a shortcut model of another seed must
\emph{keep} the shortcut (at least 80\% of the gap), or a removal may only mean that swapping broke the model.

\textbf{Activation patching.} Each test review is run with name A and with name B, which differ only at the four name
tokens. In the run with A we replace, at layer $L$, the hidden states at a set of positions with those from the run
with B. The share $F$ of the change in $d$ that this transfers shows how much of the name's effect is carried at that
layer and position. We patch the name tokens ($\Fn$), the last token ($\Fl$), and all other positions.

\subsection{Repairing the shortcut}
\textbf{Single-block retraining.} Starting from a shortcut model, we retrain one transformer block for one epoch on
the clean-twin data and keep everything else frozen, including the embeddings, the final layer norm and the output
matrix (\retrainParamsOneBlockFullFT{}M trainable parameters for one GPT-2 block). Retraining all twelve blocks the
same way (\retrainParamsAllFullFT{}M) is our all-block baseline; it is not full fine-tuning, because the embeddings and
output stay frozen. Retraining on the shortcut data itself is the control.

\textbf{Read-out.} As a training-free comparison, we also carry the last-token state of an intermediate layer forward
to the output (Section~\ref{sec:readout}).

We distinguish predictions we wrote down and committed before running an experiment (\emph{registered}) from patterns
we noticed afterwards (\emph{post hoc}); two late follow-ups, the word cue and the Yelp data of
Section~\ref{sec:othercues}, are exploratory. Appendix~\ref{app:prereg-rest} lists every registered prediction and
whether it was met. All numbers are generated from the committed result files.
